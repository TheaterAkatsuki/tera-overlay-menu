## 🧩 About

**TERA Overlay Menu** is a curated list of TERA open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD customization, cooldown tracker
- **Quality-of-Life Helpers** — inventory manager, chat filter, overlay notes
- **Research Notes** — dungeon layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Cooldown Tracker — track skill cooldowns and buffs
- Target Info — display target health and status
- Range Indicator — visualize skill ranges for study
- Combo Notes — record and review skill rotations

### Wallhack
- HUD Editor — move and resize UI elements
- Custom Skins — organize player cosmetics
- Chat Filter — filter chat messages and notifications
- Minimap Overlay — enhanced minimap with markers

### Aimbot
- Inventory Manager — sort and organize items
- Bank Search — quick search in bank and inventory
- Auto Loot Notes — track loot drops for study
- Teleport Notes — save and load locations for practice
